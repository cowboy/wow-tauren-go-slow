# Tauren-Go-Slow (WoW Forever)

A WoW Forever addon that automatically cancels the Tauren Plainsrunning aura. Great when you're running around and questing with non-Tauren friends.

## Slash commands

`/tgs` is an alias for `/taurengoslow` and accepts the same arguments.

| Command | What it does |
| --- | --- |
| `/taurengoslow` | Toggle auto-cancel on or off |
| `/taurengoslow on` | Enable auto-cancel |
| `/taurengoslow off` | Disable auto-cancel |

Any other argument prints a usage message.

## Key binding

Bind a key to toggle auto-cancel under Key Bindings → Cowboy → Tauren-Go-Slow.

## Notes

Auras can only be canceled out of combat. If you gain Plainsrunning during combat, it's canceled as soon as combat ends.
